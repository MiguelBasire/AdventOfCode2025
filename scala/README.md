# AdventOfCode2025

## Purpose

This `sbt` project is a `scala + fs2` naive implementations of the first 8 days
of the advent of code 2025.

## Organization

Each day of the advent of code has been split into 2 parts:

* The first (easy) part name file begins with `Day##` where `##` stands for the day number.
* The second part name file begins with `Day##Part2`.

## Run a test

`sbt run` then choose the matching test file.
